# Backend Go + Gin: Fresher → Senior

Giáo trình tiếng Việt về lập trình backend với Go và framework Gin, đi từ nền tảng đến mức thiết kế hệ thống.

**Tác giả:** Mai Anh Khôi

## Nội dung

- 9 giai đoạn (1–8, kèm Giai đoạn 3B), 65 buổi học, khoảng 1.300 trang
- 5 dự án thực hành, 8 phụ lục (A–H)
- **Giai đoạn 3B:** phân tích yêu cầu, use case, ERD, thiết kế API (OpenAPI) trước khi code
- **Giai đoạn 8:** system design (nhất quán và nhân bản, phân mảnh, điều phối phân tán, log/stream, feed/chat, rate limiter, tìm kiếm, sổ cái/thanh toán, chịu lỗi)

## Lưu ý

Các phần cần hạ tầng không có sẵn trên máy tác giả (Docker daemon, Kubernetes, AWS, Kafka, đa vùng) được ghi rõ là không chạy thực tế, không có đầu ra giả.
